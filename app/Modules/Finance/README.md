# Modul 1: Finance & Budgeting

## Domain Overview
Manajemen akuntansi keuangan terpusat, penganggaran departemen, rekonsiliasi kas/bank, pelaporan performa Balanced Scorecard (BSC), serta fungsi Real-Time Budget Gatekeeper untuk seluruh pengeluaran perusahaan.

## Schema Data Inti
- `chart_of_accounts`
- `cost_centers`
- `budgets`
- `journal_entries`
- `journal_items`
- `bsc_metrics`

## Fitur Utama
1. Sinkronisasi Read-Only Odoo GL & Custom COA Mapping
2. Jurnal Penyesuaian (AJE) Maker-Checker
3. Trial Balance 4-Kolom & Financial Statements
4. Flexible Budget Engine & Real-Time Gatekeeper API
5. NPD Sales Attribution (365 Days)
