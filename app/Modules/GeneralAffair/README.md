# Modul 2: General Affair (FPUGA)

## Domain Overview
Pemeliharaan sarana/fasilitas pabrik, pengelolaan permintaan ATK/Rumah Tangga, manajemen aset tetap multi-plant, keamanan pabrik (QR patrol), dan layanan HelpDesk IT.

## Schema Data Inti
- `ga_work_orders`
- `ga_atk_requests`
- `ga_atk_items`
- `assets`
- `asset_depreciations`
- `patrol_logs`

## Fitur Utama
1. Siklus Work Order Berkesinambungan (Form A -> Form B -> Form C -> Form D)
2. Permintaan ATK & RT Bertingkat dengan revisi otomatis
3. Manajemen Fixed Asset Multi-Plant & QR Labeling
4. Mobile QR Patrol Security & Cleaning Anomaly Tracking
5. IT HelpDesk 9-Stage Project Lifecycle
