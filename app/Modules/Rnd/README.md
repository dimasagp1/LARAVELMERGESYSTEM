# Modul 7: R&D (NPD Management)

## Domain Overview
Pengelolaan siklus hidup riset produk baru (New Product Development), eksperimen preformulasi, penciptaan formula RM/PM, pengujian stabilitas, hingga penyusunan dokumen registrasi BPOM (NIE).

## Schema Data Inti
- `npd_projects`
- `npd_formulations`
- `formulation_items`
- `npd_stability_tests`
- `npd_dossiers`

## Fitur Utama
1. 3-Fase Siklus Pengembangan Produk (Insight -> Development -> Commercialization)
2. Kalkulator HPP Simulasi & Formulasi Presisi 100%
3. Sensory Panel Test & Suite Uji Stabilitas (Real-Time vs Accelerated)
4. BPOM Dossier Export System (e-Registrasi Structure)
5. Master BOM Promotion ke Produksi Komersial
