# Modul 3: HRIS (HRISNOW)

## Domain Overview
Pengelolaan siklus hidup karyawan, presensi berbasis biometrik & geofencing, penjadwalan shift, manajemen lembur/Time Bank, penggajian (payroll TER), serta manajemen sasaran mutu Strategic Performance BSC Level 3 & 4.

## Schema Data Inti
- `employees`
- `attendances`
- `time_banks`
- `payrolls`
- `bsc_l3_targets`

## Fitur Utama
1. Presensi Biometrik & Geofencing Anti-Spoofing
2. Shift Roster & Time Bank Engine
3. Kaizen Kizuki & Kaizen Point System
4. Payroll Engine TER (Tarif Efektif Rata-rata) & Encrypted PDF Slip
5. Strategic Performance BSC L3 & L4
