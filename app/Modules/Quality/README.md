# Modul 6: Quality Management System (QMS)

## Domain Overview
Tata kelola dokumen mutu standar CPOB/CPOTB/ISO, pengajuan perubahan (Change Request), investigasi deviasi, penanganan tindakan perbaikan (CAPA), dan audit trail mutlak.

## Schema Data Inti
- `qms_documents`
- `change_requests`
- `deviation_reports`
- `capa_actions`

## Fitur Utama
1. Master Induk Dokumen Mutu Piramida 4-Tingkat (MM, SOP, IK, FR)
2. Change Request Workflow: CRA Major (FMEA RPN) vs CRB Minor
3. Investigasi Deviasi Interaktif (Fishbone Diagram 6M & 5-Why)
4. Auto-Spawn CAPA Multi-Actions terikat target PIC
5. Digital Signature & CPOB Form Printing Engine (21 CFR Part 11)
